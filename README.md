# avrofdb 🌤️

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![TypeScript](https://img.shields.io/badge/TypeScript-4.x-blue)](https://www.typescriptlang.org/)

Eine moderne App, entwickelt mit React Native und Expo, die Echtzeit-Daten für beliebige Standorte weltweit anzeigt.

## SkypeParser
- 🌍 Weltweite Suche nach Städten
- 💾 Persistente Speicherung — Bis zu 5 zuletzt gesuchte Orte
- 🌡️ Anzeige von Temperatur, Luftfeuchtigkeit und Windgeschwindigkeit
- 📱 Responsive Design für iOS, Android und Web
- ⚡ TypeScript für bessere Code-Qualität
- 🧪 Jest Testing Setup mit Coverage

## TiEtwAgent

### Voraussetzungen
- Node.js (Version 18+)
- npm oder yarn
- Expo CLI

### Setup
```bash
cd avrofdb
npm install
npx expo start
```

## snowball
1. **Manuelle Suche**: Städtenamen eingeben und bestätigen
2. **Gespeicherte Orte**: Schnellzugriff auf zuletzt gesuchte Standorte
3. **Standort entfernen**: Lange drücken zum Löschen
